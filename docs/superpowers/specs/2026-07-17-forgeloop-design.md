# ForgeLoop 设计记录

本设计按 Superpowers `brainstorming` 流程形成。课程要求的完整、规范化设计位于仓库根目录 [`SPEC.md`](../../../SPEC.md)，该文件是唯一规范来源。

## 已批准方向

- 产品：带 Web 控制台的安全 Coding Agent Harness。
- 主要贡献：确定性反馈闭环，包括失败分类、指纹、重复动作与无进展检测。
- 次重点：路径围栏、危险命令策略和动作绑定的一次性 HITL 审批。
- 技术栈：Python、FastAPI、SQLite、pytest、Docker。
- 边界：自行实现主循环；不使用任何高层 Agent 框架。

## 核心流程

```text
任务 -> LLM 单次决策 -> JSON 动作 -> 策略审查 -> 工具执行
     -> 验证器 -> 失败分类/进展判断 -> 反馈回灌 -> 下一轮或停止
```

## 设计授权

在展示反馈闭环、治理、扩展工具和记忆四种方向后，使用者授权助手按推荐的“反馈闭环为主、治理为辅”方案持续推进至可交付版本。详细验收标准、安全模型、数据模型和模块规约见 `SPEC.md`。
